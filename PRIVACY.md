# Privacy Policy — Rush22

_Last updated: 2026-09-01_

Rush22 is a personal, non-commercial automation script that generates short
videos and publishes them to a single YouTube channel on a schedule via
GitHub Actions.

## What this app accesses

Rush22 uses the YouTube Data API v3, authorized via Google OAuth, solely to
upload videos to the one YouTube channel its owner controls. It does not
read, collect, or share data belonging to any other Google account, channel,
or viewer.

## Data handling

- OAuth credentials (client ID/secret, refresh token) are stored only as
  encrypted GitHub Actions secrets and are never shared with third parties.
- No end-user or viewer data is collected, stored, or processed by this app.
- Generated video content and upload logs are stored in this GitHub
  repository, which is public.
